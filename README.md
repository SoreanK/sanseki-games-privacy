# Sanseki Games — Privacy Policy

This repository hosts the Privacy Policy page for all applications published by **Sanseki Games** on the Google Play Store.

The page is published via GitHub Pages at:

**https://soreank.github.io/sanseki-games-privacy**

(Once the repo is created and Pages is enabled)

## Usage

Use this URL in the Google Play Console "Privacy Policy" field for any app published under Sanseki Games.
